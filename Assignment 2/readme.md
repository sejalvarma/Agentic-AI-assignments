# LangFlow Smart Bot – Market Research and Sentiment Analysis

## Project Overview

This project involves creating an AI-powered chatbot using **LangFlow** and a Large Language Model (LLM).

LangFlow provides a visual interface that allows different AI components to be connected without writing extensive code. In this project, the Chat Input, Prompt Template, Language Model, and Chat Output components work together to process user queries and generate responses.

The chatbot is designed for **market research and sentiment analysis**. It acts as a market research analyst and examines the text provided by the user to identify opinions, understand customer sentiment, and generate useful insights.

## Objectives

The main objectives of this project are:

- Create an AI chatbot using LangFlow.
- Learn how to connect different components to build an AI application.
- Use a Prompt Template to give the AI clear instructions.
- Take user queries or text as input through the Chat Input component.
- Process the input using a Large Language Model.
- Display the generated answers through the Chat Output component.

## Workflow Architecture

The chatbot follows the workflow below:

User Enters Text or Query
          ↓
       Chat Input
          ↓
    Prompt Template
          ↓
     Language Model
       (Llama 3.1)
          ↓
      Chat Output
          ↓
   AI-Generated Answer

The user enters a query or text, which is passed to the Prompt Template for processing with the required instructions. The Language Model then analyzes the input and generates a response, which is displayed through the Chat Output component.
